# Noobius realm social images

Five 1920 × 1080 promotional composites for desktop/X posts:

1. `01-commons-social.png` — Crew Commons and salvage.
2. `02-thermal-social.png` — Cooling Works and coolant routing.
3. `03-gpu-social.png` — GPU District and workload scheduling.
4. `04-core-social.png` — Archive Depths and checkpoint recovery.
5. `05-four-realms-social.png` — the four-realm overview.

The scenes are rendered from the game's realm geometry and combined with Noobius character cutouts, thought bubbles and explanatory callouts. They are promotional composites, not literal screenshots of a live player in an unlocked realm. Player-visible token gates and gameplay still depend on the deployed game configuration.
